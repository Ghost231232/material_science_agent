# GHOST — Personal Archive（阶段 2：首页静态响应式原型）

做点东西，记下所想。个人作品集 + 博客 + 创作档案。
当前为零依赖静态站点（HTML / CSS / 原生 JS），无需构建。

## 本地运行

在本目录（`site/`）下执行：

```bash
python -m http.server 8000
```

然后浏览器打开 http://localhost:8000

（也可以直接双击 `index.html` 打开。）

## 文件结构

```
site/
├── index.html            # 首页：Hero / 精选作品 / 最近随笔 / About / 页脚
├── assets/
│   ├── css/style.css     # 视觉系统：深蓝 + 暖白 + 红橙，响应式
│   ├── js/data.js        # 站点内容数据（集中管理，当前均为占位内容）
│   ├── js/main.js        # 数据渲染、导航状态、移动菜单、滚动淡入
│   └── tide.svg          # 红橙手绘潮水主视觉（含涌动动画）
└── README.md
```

## 已实现

- 海报式悬浮导航：透明覆盖 Hero，滚动后转为暖白半透明；含移动端菜单。
- Hero：左侧文案（GHOST / PERSONAL ARCHIVE、主副标题、歌德德文引文、向下探索），右侧红橙潮水出血展示，潮水横向缓慢涌动。
- 精选作品：暖白底、交错双列、不同封面比例与错位节奏；数据驱动渲染。
- 最近随笔：编辑式文字列表（日期 / 分类 / 标题 / 摘要）。
- About：深蓝背景左右分栏，兴趣方向，边缘低权重红色手绘线条。
- 页脚：品牌、社交占位链接、结束语与版权。
- 响应式：手机端文案在上潮水在下、作品单列、About 上下排列。
- 尊重 `prefers-reduced-motion`。
